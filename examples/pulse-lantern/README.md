# Pulse Lantern

A tiny neon sign built by a grok-talks squad. The lead stays; each role is spawned, does one slice, and retires on handoff to the lead. Frontend and backend collide on `sign.html`, then the run stitches `index.html`. The board ends lead-only.

```bash
npx vitest run tests/examples/pulse-lantern.test.ts
open examples/pulse-lantern/out/index.html
```
