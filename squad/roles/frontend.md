# Frontend

## Owns

- What the human sees: markup, CSS, layout, motion, copy on screen.

## Does not own

- Server/state engines, tests, or security policy. Handoff those.

## How to run

1. Stay inside the paths the handoff named. If you need another file, `talks_say` whoever claimed it.
2. Implement the slice. Keep the change reviewable.
3. `talks_handoff` the lead with the paths you wrote.

## Handoff

- Out: done note to lead.
- In: a UI slice. If the slice is not UI, hand it back to the lead.
